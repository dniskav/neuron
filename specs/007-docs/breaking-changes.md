# Inventario de cambios incompatibles de la 0.4.0 (T001)

Fuente única de `CHANGELOG.md`, README y `AGENTS.md`. Describe el estado NETO de `HEAD` frente a 0.3.2 (`723fa58`), no la historia de lotes.

## Cómo se verificó

- **Base:** rama sobre `fix/v0.4` = `f956f48`. `git diff --quiet d0228b7 -- src` sale 0 (la 007 no ha tocado `src/`). `git diff --stat 723fa58..957d618 -- src` está vacío: la feature **002 no cambió `src/`** (solo pruebas), así que no aporta filas. `src/index.ts` y `package.json` coinciden con `d0228b7`; `version` sigue en `0.3.2`.
- **Método.** Cada fila se contrastó con el código actual. Se construyó `dist/` de `HEAD` y una copia del `dist/` de 0.3.2 (worktree temporal en `723fa58`, fuera del repositorio) y se ejecutaron sondas `t001_*` en el scratchpad (no commiteadas) con el mismo caso contra las dos versiones. Los valores «antes» y «ahora» de la tabla son los medidos, salvo donde se indica.
- **Columna «Verif.»:** `S` = sonda ejecutada (script `t001_*`; entre paréntesis el caso o las cifras); `L` = lectura de `src/` actual (`archivo:línea`); `D` = lectura del `git diff 723fa58..HEAD -- src/<archivo>`; `H` = cifra o afirmación tomada de `HANDOFF.md` o de las notas de 006 y **no reproducida** («a verificar», con el motivo).
- **Claves de origen:** `H:n` = línea `n` de `specs/HANDOFF.md` (107 = «Cambios observables de 003»; 114 = 004; 115 = limitación tras 004; 117 = 005 I2/I7; 119 = «Estado de 005 (parcial)»; 121 = «adicionales de 005 (T013–T016)»; 123 = aplazados a 007; 35 = «adicionales de 006, Lotes 9–12»; 45 = «de 006»; 41 = notas para 007). `T0xx` = tarea o nota por lote de `specs/006-coverage/tasks.md` (Lotes 9–13, T048, T060, T064, T065 y «Decisiones del usuario (2026-11-11)»). `D` = `git diff` citado.
- **Sondas con tolerancia:** donde se compara una trayectoria numérica entre versiones, la diferencia máxima y el veredicto detallado son de T014 (`migration-evidence.md`); aquí solo se dan las mediciones necesarias para validar la receta.
